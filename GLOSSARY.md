# Skills Template

This repo is a GitHub template that bootstraps new projects with Matt Pocock's engineering skills installed and pre-configured.

## Language

**Template**:
This repository — the source that consumer projects are created from via GitHub's "Use this template" button.
_Avoid_: Starter repo, seed repo

**Consumer project**:
A new repository created from this template, inheriting its skills, agent conventions, and domain docs.
_Avoid_: Clone, fork

**Custom skill**:
A workflow skill written for this template that ships to every consumer project; added only when no existing skill covers the task.
_Avoid_: Plugin, module, add-on
